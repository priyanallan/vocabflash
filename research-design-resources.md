# Design Resources (free) — for the German vocab flashcard app

Curated free resources to select a visual direction for the A1–B2 flashcard app.
Direction so far: **clean, calm, content-first** (D23) — big legible card, minimal chrome.

## Design systems & kits
- **Material Design 3** — `m3.material.io`. The canonical free design system; **Material 3 is built
  into Compose Multiplatform**, so following it means near-zero design-to-code friction.
- **Material Theme Builder** — `m3.material.io/theme-builder`. Generates a full colour/tone token set
  from one seed colour; exports tokens you can drop straight into a Compose theme.
- **Material 3 Figma kit** — free Figma file; duplicate and use as a component base.

## Templates / community files (Figma)
- Search Figma Community for **"flashcard"** and **"language learning"** — many free mobile UI kits.
- Search **"mobile UI kit free"** for generic component libraries.
- These give layout/flow inspiration (card fronts, review screens, progress screens).

## Iconography & illustration
- **Lucide** (MIT) — clean line icons; has official Compose/Material implementations.
- **Material Symbols / Icons** — free, included with Android/Compose.
- **unDraw** (free, open-source style) and **illlustrations.co** (free) for illustrations if wanted.

## Fonts (Google Fonts, free, OFL)
All German-safe (must cover umlauts ä ö ü, ß, and uppercase):
- **Inter** — neutral, legible, excellent for UI chrome.
- **Rubik** — slightly rounded, friendly; good for a calm-but-warm feel.
- **Source Serif 4 / Lora** — for a more bookish, textbook feel on the card itself.
- Note: font choice matters for reading German long words — prefer generous letter-spacing options.

## Reference apps to study (UI/UX patterns, not assets)
- **AnkiDroid** (open source, GPL) — SRS review flow, card templates, scheduling UI.
- **Anki** (open source) — desktop reference for the review workflow.
- **Duolingo** — streak/habit patterns and grading feedback (study the interaction, not the assets).
- **Quizlet / Brainscape** — card-deck and browse/search patterns.

## Inspiration galleries
- **Dribbble / Behance** — search "flashcard app", "language learning app", "spaced repetition".
- **Mobbin / Mobbin-like free archives** — real-app UI reference for travel-friendly mobile apps.

## Suggested next step
Pick 2–3 reference apps + one Figma kit and one font pairing; a quick taste test on a phone decides
the direction. Keep the palette to **one seed colour + neutral greys**, reserving colour for
correct/wrong feedback.
